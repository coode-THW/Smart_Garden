# 🌸 智慧花园 — 养护知识 JSON 数据目录

本目录存放所有花卉品种的结构化养护数据，供 `KnowledgeService.ts` 加载使用。

---

## 数据规范

每个花卉一个 JSON 文件，文件名为 `{花名}.json`，例如 `月季.json`。

## 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| flowerId | number | ✅ | 唯一ID。1-5 为 YOLO 已训练的 5 类，6+ 为其余品种 |
| flowerName | string | ✅ | 中文名称，与文件名一致 |
| scientificName | string | ✅ | 拉丁学名（斜体） |
| family | string | ✅ | 科属信息，如"蔷薇科蔷薇属" |
| origin | string | ✅ | 原产地 |
| bloomPeriod | string | ✅ | 花期，如"4-9月" |

### watering（浇水建议）

| 字段 | 必填 | 填写要求 |
|------|------|----------|
| frequency | ✅ | 具体频率，如"每周2-3次"、"每天1次" |
| amount | ✅ | 水量描述，如"浇透水直至盆底有水流出"、"表面湿润即可" |
| timing | ✅ | 最佳浇水时间，如"早晨或傍晚" |
| method | ✅ | 浇水技巧，如"从盆边缓慢浇灌" |

### fertilizing（施肥建议）

| 字段 | 必填 | 填写要求 |
|------|------|----------|
| period | ✅ | 施肥周期，如"生长期每月1次"、"花期前增施磷钾肥" |
| amount | ✅ | 具体用量，如"复合肥10-15克/次" |
| recommended | ✅ | 推荐肥料列表，至少 2 种，含稀释比例 |

### lighting（光照要求）

| 字段 | 必填 | 填写要求 |
|------|------|----------|
| requirement | ✅ | 光照需求，如"每天至少4小时阳光" |
| bestLocation | ✅ | 最佳摆放位置，如"南向阳台" |

### environment（环境要求）

| 字段 | 必填 | 填写要求 |
|------|------|----------|
| temperature | ✅ | 适宜温度范围，含冬季/夏季说明 |
| humidity | ✅ | 适宜湿度，如"50-70%" |
| ventilation | ✅ | 通风要求，如"良好"、"需避免风口" |

### pests（病虫害防治）

至少 2 条。每条包含：

| 字段 | 必填 | 填写要求 |
|------|------|----------|
| name | ✅ | 病虫害名称 |
| symptom | ✅ | 症状描述（含发病部位和外观特征） |
| treatment | ✅ | 防治方法，含具体药剂名和稀释倍数 |

### operations（养护操作）

至少 1 条。每条包含：

| 字段 | 必填 | 填写要求 |
|------|------|----------|
| name | ✅ | 操作名称，如"换盆"、"修剪" |
| frequency | ✅ | 操作频率，如"每年春季" |
| steps | ✅ | 操作步骤数组，至少 3 步 |

## 质量要求

- [ ] 所有字段不为空（暂无数据填"待补充"，不可删除字段）
- [ ] pests 至少 2 条不同病虫害
- [ ] operations 至少含"换盆"（如适用）
- [ ] 药剂名称和稀释倍数为具体数值（如"多菌灵1000倍液"）
- [ ] 中文描述通俗易懂，面向家庭养花用户
- [ ] JSON 语法有效（可用 `python -m json.tool` 校验）

## 数据来源

- 拉丁学名/科属/原产地：百度百科、植物智 (iplant.cn)
- 养护数据：园艺权威书籍、资深花友经验、复合肥厂商官方说明
- 病虫害防治：中国农业出版社植保手册
